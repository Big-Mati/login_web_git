### 🔐 Descripción del Proyecto

**Login Web** es una interfaz moderna de autenticación e inicio de sesión desarrollada con **HTML5 y CSS3**. El proyecto se enfoca en el diseño limpio de formularios de acceso, campos de entrada (*inputs*) estilizados, botones interactivos y una disposición visual centrada y adaptable.
